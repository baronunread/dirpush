# IndieLineup

- No account. /submit/ is a 4-step form: URL (Auto-fill), details, plan, badge.
- Choose 'Free' to get a badge snippet: <a href="https://indielineup.com/product/<slug>?ref=badge" rel="dofollow"> with image /badge/<slug>.svg. Add it (e.g. footer) then click Verify Badge.
- Badge already live on submit = listing live immediately; otherwise review within 7 days.
- Removing the badge later unpublishes the listing after 7 days.
- Pick up to 3 categories from a fixed list.

# FranceSaaS

- Start at https://francesaas.fr/soumettre and choose a listing tier. The page defaults to Premium (€99 HT); select the €0 free tier deliberately if using it.
- Free submission enters a multi-week review queue and requires the FranceSaaS badge in the product site's footer for as long as the listing remains active. Express costs €39 HT, publishes within 24 hours, and has the same badge requirement. Premium costs €99 HT, publishes immediately, and does not require a badge.
- The directory is for SaaS available and relevant to the French market. Account and product-detail fields appear later in the form; no account was created and no listing submitted.

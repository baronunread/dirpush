# eBool

- Submit at https://www.ebool.com/submit (old /submit-listing URL now 404s).
- Form bundles account signup (name/email/password) with the listing details (product name, website URL, optional company/country, description 100-500 chars, logo upload PNG/JPG/SVG max 100KB, primary category) in one flow, then 'Continue to Review'.
- Plan picker at the top of the same page: Free (~6 month queue) / Premium $47 / Pro $117 / Super $197, all one-time payments.
- No badge/backlink requirement anywhere on the pricing/comparison table; free tier's only cost is a long queue, everything else (paid tiers just get faster approval, more categories, and ranking/homepage exposure).
- A prior real submission attempt hit an invisible reCAPTCHA at the final submit step that blocked an automated browser - expect to need a human or headed session to get through the last click.
- Listing pages that showcase a product live at /alternatives/{slug} (e.g. /alternatives/docunest); there's no separate bare per-product URL, only category-page anchors and alternatives pages.

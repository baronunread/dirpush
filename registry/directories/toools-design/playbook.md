# TOOOLS.design

- No account needed. Go to /suggest-a-tool.
- Fields: Link URL, Tool Name, Tool Description (max 120 chars, live counter), Category (dropdown, 19 options e.g. AI Tools/Design Tools/UX Tools/Productivity), Pricing (Free/Freemium/Free+Paid/Free Trial/Paid/Beta), optional contact email and message.
- Directory is design-tool focused ('carefully curated... only design-related and genuinely useful tools will be considered').
- Free listing subject to manual review; no stated timeframe; no badge or backlink required to go live.
- Optional paid promotion via /sponsor: $200/mo homepage feature, $100 category feature, or newsletter placement bundles ($175/$325) - none required for a free listing.
- Listed tools link straight out to the tool's own site; there's no internal per-tool detail page, so no listing_url_pattern to give.

# Dofollow.Tools

- Sign-in required to submit (button visible top-right); /submit is a 2-step wizard (Tool Information, then Submission Type where you pick Free vs a paid tier).
- Description requires a minimum of 500 characters (markdown supported), up to 5000.
- Auto-fill button uses AI to pull name/tagline/description/logo from the entered tool URL.
- Free listing goes live after a 7-day queue regardless of the badge; the badge only keeps the backlink dofollow (remove it and the link drops to nofollow, listing stays).
- Same operator also runs firstlook.tools (bundled in the $25.90 'Dual Directory' tier) — worth checking as a separate candidate.

# EU Software Alternatives

- Submit through https://eusoftwarealternatives.eu/submit-software/. The public form requests company/contact details, headquarters country and website, affiliate-program status, and structured software information. Short description is limited to 200 characters; list up to four features.
- The listing is free; affiliate participation is not required. Editorial review does not guarantee inclusion.
- Eligibility is strict: vendor HQ in EU/EEA/UK/Switzerland, majority ownership in those jurisdictions, and European hosting as a default or standard option.

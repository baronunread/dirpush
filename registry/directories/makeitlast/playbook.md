# MakeItLast

- Sign in required (Google or magic-link email) before /submit works; browsing the catalog itself needs no account.
- Flow: paste product URL -> AI auto-drafts name/tagline/description/category/tags -> save -> automated review runs immediately -> if it passes, choose link type.
- /submit form requires exactly 5 tags and a logo upload; supports up to 3 screenshots (optional).
- Link choice radio defaults to 'Dofollow + badge': switch it to 'Nofollow' to publish for free with zero strings (button label changes to 'List as nofollow') - listing goes live immediately on save either way. 'Dofollow + badge' (free, must display a badge on your homepage, re-checked weekly) or 'Dofollow no badge' ($9 one-time, charged only after review passes) are the alternatives if you want a dofollow link.
- Separate $49 'homepage ad' upsell exists (30-day featured slot), unrelated to basic listing.
- Live listings sit at https://www.makeitla.st/tools/{slug} (confirmed via a real entry, p2p-companion).

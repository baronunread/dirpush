# AI Tool Hunt

- No account needed; form at /submit-ai-tool/ is a single page.
- Choose the 'Free Listing - $0 - Not Guaranteed' radio option (the $15 'Priority Review' is preselected by default, so switch it).
- Fields include a plain text 'AI Tool Category' box (not a dropdown) and a required Logo/Favicon URL field, plus a consent checkbox. No badge or backlink required to go live.
- Accepted tools do not get a dedicated page on aitoolshunt.com - they appear as ranked entries embedded in a category page (e.g. /ai-writing-tools/) with a 'Know More'/'View Tool' link pointing straight to the product's own site, so there's no internal listing URL to check afterward.

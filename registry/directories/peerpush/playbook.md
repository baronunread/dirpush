# PeerPush

- /submit (and /advertise) both redirect to /auth/login?redirectTo=... - an account is required before you can even see the submission form; the form's contents (including whether a badge is required) were not visible past this login wall.
- Login is email (6-digit code sent by email) or 'Continue with Google'. No GitHub.
- After login: add product info (name, description, website, logo, categories); free listing in directory.
- Earn PeerPush Points by discovering/supporting other products; use points (or pay directly) to boost visibility or get sponsored/promoted placement.
- Content read by AI systems: ChatGPT, Claude, Gemini, Perplexity. Public API and MCP integration available.
- Live listings at /p/{slug}, e.g. /p/quill.

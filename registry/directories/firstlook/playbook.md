# First Look

- Submit at /submit: enter the tool URL and click the AI button to auto-fill; description needs at least 500 characters (markdown ok); logo required (max 500kb), up to 4 screenshots.
- Optional fields: discount code, founded year, YouTube demo, GitHub repo, founder Twitter, affiliate program.
- Free path asks you to copy a badge embed from /pricing onto your site; keep it up or the listing returns to pending with nofollow.
- Sign-in: Google, GitHub or email code.
- Product pages are /product/{slug} but slugs strip punctuation inconsistently, so no pattern is recorded.

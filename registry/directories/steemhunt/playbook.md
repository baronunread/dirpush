# Steemhunt

- Login is NOT email/Google — it needs a Steem blockchain username + posting key. There's no visible standard signup form on /sign-in; creating a Steem account normally requires an external onboarding flow (e.g. steemit.com), which is outside read-only research.
- No /pricing page; no paid boost/featured tiers or badge/backlink requirement found anywhere on the site.
- Posting ('hunting') a product rewards both hunter and product with STEEM cryptocurrency payouts based on upvotes.

# FastLaunch

- The old /submit URL 404s; use the 'Submit Project' nav link, which is really /projects/submit.
- Signing in is required first (Google or GitHub only, no email) - it redirects to /sign-in?redirect=/projects/submit.
- Daily (not weekly) launch cohort model, 5 free slots/day, launches go live 8:00 AM UTC.
- Free listing has no condition attached; only the dofollow backlink is conditional on placing top-3 that day.
- $9.90 (normally $29, 65% off) Premium skips the queue, guarantees dofollow, gets 1-year homepage feature.
- $149 (was $299) Sponsor tier: homepage spot + badge for a year, contact support@fastlaunch.io after payment.
- General product categories (AI, SaaS, e-commerce, music, security tools all seen on homepage) - broad audience, not AI-only.
- Live listings sit at /projects/{slug} (e.g. /projects/love-tales).

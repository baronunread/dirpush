# Navs Site

- /submit is a 7-step wizard: Basics, Media, Features & FAQs, Pricing, Details, Alternatives, Review - no login required to start.
- Free tier: auto-published with no manual review, website-submissions only, nofollow link, no featured placement, no API - none of these are conditions to satisfy, just what the free tier includes. No badge/backlink required to go live.
- Standard/Pro paid plans (credit-based) add dofollow links, featured placement, and API access.
- Live listings sit at /website/{slug} (e.g. /website/chatgpt).

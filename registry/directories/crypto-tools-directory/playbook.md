# Crypto Tools Directory

- Submission starts by entering the tool's real product domain (no link shorteners/localhost) at /submit-new-tool, then continues into a multi-step form. No login required to begin.
- Required listing fields per the site's own launch guide: unique product name (max 40 chars), description, thumbnail, tagline (max 60 chars), gallery images, launch tags, contact email.
- Choose the 'Free' Tools Listing Plan (not Missile/Rocket/Starship) to avoid payment; free review takes ~4 weeks. No badge or backlink required to go live.
- Note: 'Airdrops Listing Plan' ($199, no free tier) is a separate listing category for token airdrops, not the general tool submission.

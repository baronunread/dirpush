# MacNative

- Only for native macOS apps (menu bar utilities, dev tools, creative software) — not general SaaS/web products. Explicitly rejects browser wrappers.
- /submit requires 'Sign In'; auth is Google-only ('Continue with Google'), no email/password option.
- Free plan: listing page with screenshots/gallery, basic analytics, embeddable 'Featured on' badge, standard review queue — no strings attached, manual human review with no guaranteed acceptance. FAQ explicitly confirms Pro is not required to submit or go live.
- Pro ($19/app/month, billed per listing after submission) is purely optional: homepage/category featured placement, priority review, unlimited screenshots, a separate Pro badge, newsletter mention, GitHub 'Awesome Native macOS Apps' inclusion.

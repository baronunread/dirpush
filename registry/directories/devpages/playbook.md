# DevPages

- Use the dedicated form at /submit-a-tool (sidebar link 'Submit a tool'), not just the generic /contact form.
- No account needed. Fields: Tool Name, Description, Website URL, Category (dropdown of 21 categories), Pricing (dropdown, defaults to Free), optional GitHub URL, optional Tags, and Your Email.
- Page states explicitly: 'every submission is read by hand, and listings are free.' No badge or backlink required to go live.
- Live listings follow https://devpages.io/tool/{slug} (e.g. /tool/kubernetes).
- 21 categories including DevOps, Cloud Infrastructure, Observability, APIs, Frameworks, Databases, Security, etc.

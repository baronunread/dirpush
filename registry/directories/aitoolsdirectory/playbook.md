# AI Tools Directory

- Old /submit-ai-tool URL 404s now; use /submit-tool (reached via the 'Submit Tool' nav link) - form is embedded inline (iframe), no separate account needed.
- Fill product name, URL, pricing (dropdown), short description (20-30 words), long description (50-500 words), tags, submitter name/email, optional twitter handle/affiliate URL, what makes it unique, and ad interest.
- Every tool is manually reviewed; free review can take a while - paid Fast Track gets same-day-to-3-day turnaround.
- Hard rules: no crypto products, no waiting-list/hidden-pricing products, descriptions must be original (AI-generated or copied text gets discarded), must be clear what the product does within 5 seconds.
- No badge/backlink requirement anywhere to submit or go live.
- Separate paid 'Featured Tool homepage spot' also exists for immediate organic-listing placement.

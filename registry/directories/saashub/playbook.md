# SaaSHub

- Correct submit form is https://www.saashub.com/services/submit (nav 'Submit Product'). Do NOT confuse with /submit or /submit/list, which is a different free tool listing 110 OTHER submission sites.
- Form is URL-first: paste your product's website URL, then Continue. No login required to submit, no badge or backlink required to go live.
- Rejected: dev agencies, waitlist/coming-soon pages, unreleased products, free subdomains (vercel.app etc.), non-English sites.
- All submissions go through manual approval; verifying ownership via a domain email speeds up review but is optional.
- Optional $99/month 'Feature My Product' upsell for homepage/category promotion - unrelated to getting a basic free listing.
- Register (email + username + password + hCaptcha) is only needed to manage/claim a listing later.
- Live listings at /{slug}-alternatives, e.g. /fig-terminal-alternatives.

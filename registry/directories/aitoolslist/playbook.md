# aitoolslist.io

- No account needed; submit via a Tally embedded form at /submit-ai-tool/ (name, email, tool name, link, category, short description, additional notes).
- Editorial curation, no autofetch, no guaranteed inclusion, no badge/backlink required at any step.
- Site is a personal-brand curated listicle, not a per-tool profile database - approved tools get a mention on a category/roundup page (e.g. /best-ai-tools/) with an outbound 'Try it!' link straight to your site, not a dedicated aitoolslist.io page, so there's no predictable listing URL.
- Paid promotion / marketing-agency services exist via /sponsor-ai-tools-list/ but are quote-based (no published price).

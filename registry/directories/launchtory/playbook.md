# Launchtory

- /submit doesn't exist; the real submission form is at /projects/new, which requires login/signup before showing any fields.
- Every project must first pass a manual safety/quality review (rejects adult, gambling, phishing, scams, malware, illegal content) regardless of payment.
- No plain unconditional free tier: /pricing frames $19 one-time as buying guaranteed 1-year featured placement, while free publishing is only available via 'community votes or website link verification... when available from the project status page' - i.e. only visible/offered after your submission is approved, and gated on hitting a vote threshold or adding their backlink.

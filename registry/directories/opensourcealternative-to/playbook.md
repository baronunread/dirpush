# OpenSourceAlternative.to

- Only accepts open-source, self-hosted, actively-maintained projects positioned as an alternative to a named proprietary tool - not usable for closed-source SaaS.
- Form requires a repository link and the proprietary competitor's name/site.
- Free = 6+ month waitlist; $29 = 48h review. No login required. No badge or backlink required to go live.
- Live listings at /project/{slug}, e.g. /project/metabase.

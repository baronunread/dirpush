Startup88's old /submit-startup/ WordPress page is gone (404). The real submission path is the 'Pitch Your Startup' link on the homepage, which opens an external Typeform (https://startup88.typeform.com/to/CRjWqM) - no login needed to start it, no badge/backlink required to go live.

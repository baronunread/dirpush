# DevTools Directory

- This is an open-source community catalogue, not a hosted form. Add one YAML file in the tools content directory and open a PR.
- The contribution guide’s template asks for name, slug, website, short description, resource type, product pricing, open-source flag/license, optional GitHub/docs/logo URLs, categories, tags, platforms and languages.
- No submission fee is stated. A GitHub account is required to fork and open a PR; maintainers review contributions.
- The directory is specifically for developer tools.
- Start from https://devtools.directory/contribute/ and the current repository guide at https://github.com/devtoolsd/devtoolsd/blob/main/CONTRIBUTING.md.

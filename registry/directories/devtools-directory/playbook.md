# DevTools Directory

- This is an open-source community catalogue, not a hosted form. Fork devtoolsd/devtoolsd, add one Markdown file with YAML frontmatter at content/tools/<slug>.md, and open a PR titled "add: Name".
- Frontmatter fields: name, slug, website, description, optional long_description, tool_type (editor | framework | library | cli | devops | database | testing | api | monitoring | platform | design | other), pricing (free | freemium | paid), open_source, license, optional github, logo, docs_url, categories, tags, platforms, languages.
- Categories are slugs: backend, cli-tools, containerization, databases, devops, extensions, frameworks, frontend, ides-editors, software-engineering, terminal-tools.
- No submission fee is stated. A GitHub account is required to fork and open a PR; maintainers review contributions.
- The directory is specifically for developer tools.
- Current guide: https://github.com/devtoolsd/devtoolsd/blob/main/CONTRIBUTING.md

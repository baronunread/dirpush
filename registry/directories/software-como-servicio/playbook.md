# Software Como Servicio

- The Spanish-language public form is at /enviar.
- Free listing is presented as requiring the SCS badge on the product site, with a dofollow link to https://softwarecomoservicio.com and no UTM or other query parameters. No paid placement is offered.
- Required: tool name, homepage URL, one-line description (about 120 characters), 1–3 categories, email, and badge confirmation. X/Twitter or LinkedIn is optional.
- A human reviews each submission; badge-equipped listings appear first.

# must.tools

- No login required to fill out /submit form; it's a 2-step wizard (Tool Information, then Submission Type).
- Has an 'Auto-fill form with AI' button next to Tool URL (autofetch-like).
- Free plan requires adding a dofollow backlink badge to your site footer; badges (dark/light/transparent) are provided on /pricing.
- Description minimum 500 characters, max 5000, markdown supported.

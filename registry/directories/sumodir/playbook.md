# SumoDir

- Same template/network as dododirectory.com and sibling sites (CoveragePush, LaunchDirectories, Web Review, TinyLaunchpad, Testimly) - worth checking those for identical mechanics if they appear as future candidates.
- /submit is a public 3-step wizard, no login needed to begin.
- Free plan: 1,500-char description cap, backlink required, ~2 week review.
- $15 Premium: 2,500-char AI-written description, instant approval, no backlink.
- Payments via Polar.

# Ignlab Launch

- Submit at https://launch.ignlab.net/submit.html. No account is required; all submissions are reviewed before publication.
- Required fields: tool name (120 chars max), website URL, tagline (160 chars max), description, category, and arithmetic anti-spam answer.
- Optional fields include tags, pricing, submitter email, launch date, features, platform checkboxes, screenshot URL, maker name, X handle, and maker URL.
- The homepage has daily launch and leaderboard sections. No submission fee or optional paid listing tier was visible.

# skills.sh (Vercel agent skills directory)

- There is no submission form. The FAQ says skills "appear automatically through anonymous telemetry when users run `npx skills add <owner/repo>`". Do not look for a submit button.
- Prerequisite: a public GitHub repository containing a skill definition (`SKILL.md`) and a README. Publish it, then make installing it easy: put `npx skills add <owner/repo>` in the README and launch copy.
- The leaderboard ranks by install count only (All Time, Trending 24h, Hot). A new skill needs real installs before it shows up; do not fake installs.
- Telemetry is anonymous and aggregate (which skill was installed); users can opt out, so counts can under-report.
- The listing link points to the GitHub repository (`rel="ugc nofollow noopener noreferrer"`), not to a product site. Listing pages are indexable (no noindex found on 2 samples).
- Vercel says it cannot guarantee the quality or security of listed skills and runs routine security audits; the audit criteria are not established.
- No removal route is documented; the FAQ directs users to the skill's GitHub repo issues.
- Research only; no account needed, nothing submitted. Install counts of a specific skill and time-to-appear are not established.

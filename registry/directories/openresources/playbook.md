# OpenResources

- Public submission form: https://tools.us.org/tools/submit/. No account or login is required.
- The directory focuses on open-source software that provides an alternative to proprietary products.
- Required form fields: email, website, tool name, repository URL, proprietary software URL, and proprietary software name. Name is optional.
- Submissions are reviewed and may be declined; no review time or fee is stated. No media fields are present.

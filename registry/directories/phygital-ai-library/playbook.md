# Phygital+ AI Library

- Click 'Submit your own AI tool' (footer or top banner) - it opens an inline form on the same page, not a separate URL.
- Only 3 fields: link to the tool, a free-text description of what it does, and an optional contact/social handle so the submission can be attributed to you.
- No login, no email verification, no logo/screenshot upload, no badge or backlink required.
- No visible listing URL pattern for individual tools to confirm against a live example.

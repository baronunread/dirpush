# Awesome MCP Servers (punkpeye)

- Scope: servers with a public GitHub repository that users install and run. Remote-only hosted servers go to `awesome-remote-mcp-servers` instead.
- Steps from CONTRIBUTING.md: fork, branch, edit `README.md`, commit, push, open a PR with a clear title and description.
- Entry format seen in the README: `[owner/repo](url) [optional badge] emojis - description`. Emojis mark official status (🎖️), language, scope (☁️ cloud, 🏠 local) and OS. Add a new category only if none fits, and keep alphabetical order.
- Glama: CONTRIBUTING.md does not require a Glama listing or badge (this differs from the remote list). Many entries include a Glama score badge and the README says glama.ai/mcp/servers is synced with the repo, so a Glama listing (see `glama`) is optional but common. Not established whether maintainers ask for it during review.
- Agent PRs: add `🤖🤖🤖` to the end of the PR title to opt in to fast-track merging.
- The README is very large; edit the correct section carefully.
- Research only; no account created or listing submitted.
